About This Project

Preserving historical military records through modern technology

Project Overview

This web application modernizes access to the Soldiers Died in the Great War 1914-1919 dataset, transforming a legacy Windows CD-ROM application into a modern, searchable web interface.

The database contains 703,806 military personnel records from World War I, including both officers and soldiers who served during the Great War.

Original Work: The Access Database Era

Publisher: The Naval & Military Press Ltd.

Windows CD-ROM

The original application was distributed as a commercial CD-ROM package that included a Microsoft Access database (sd_2011.mdb), custom Windows runtime environment, and a compiled help system.

Modernization Journey

Phase A: Data Extraction

Extraction from original MDB files using mdbtools, ensuring 100% data fidelity.

Phase B: Migration to SQLite

Preservation of all 7 tables with 26 performance indexes for sub-second searching.

Phase C: Modern Interface

Development of this responsive, accessible web portal for researchers and families.
